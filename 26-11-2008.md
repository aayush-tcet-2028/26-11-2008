**Aim:** Implementation of Simple, Multiple and Logistic Regression and model performance assessment.

**Learning Objective:** To understand the concepts and applications of Simple Linear Regression, Multiple Linear Regression, and Logistic Regression.

**Tools:** VS Code, I-Python Notebook.

## Theory

### Introduction to Regression

Regression is one of the most important supervised machine learning techniques used to predict numerical or categorical outcomes based on historical data. It identifies the relationship between dependent (target) variables and one or more independent (input) variables. Regression analysis helps organizations ma ke informed decisions by forecasting future trends and understanding the influence of different factors on an outcome. It is widely used in finance, healthcare, marketing, education, manufacturing, and scientific research. Machine learning regression model s learn patterns from training data and use those learned relationships to predict outputs for unseen data. Depending on the type of target variable, different regression techniques are applied. When the target variable is continuous, Linear Regression is used, whereas Logistic Regression is applied when the target variable is categorical or binary.

### Simple Linear Regression

Simple Linear Regression (SLR) is a supervised learning algorithm used to model the relationship between one independent variable and o ne dependent variable. It assumes that the relationship between the variables is linear and attempts to fit the best straight line through the data points. The mathematical equation of Simple Linear Regression is: Y = β₀ + β₁X

### Where:

● Y = Dependent Variable ● X = Independent Variable ● β₀ = Intercept ● β₁ = Slope (Coefficient) The model determines the best values of the slope and intercept by minimizing the error between the predicted and actual values using the Least Squares Method.

### Working Process

### 1. Collect training data.

### 2. Define independent and dependent variables.

### 3. Train the Linear Regression model.

### 4. Calculate the best-fit regression line.

### 5. Predict output values.

### 6. Evaluate model performance using regression metrics.

### Applications

● House price prediction ● Sales forecasting

● Weather forecasting ● Population prediction ● Business revenue estimation

### Multiple Linear Regression

Multiple Linear Regression (MLR) extends Simple Linear Regression by considering two or more independent variables to predict a single dependent variable. It is useful when the target variable depends on multiple factors. The mathematical equation is: Y = β₀ + β₁X₁ + β₂X₂ + ... + βₙXₙ

### where:

● Y = Dependent variable ● X₁, X₂, ... Xₙ = Independent variables ● β₀ = Intercept ● β₁, β₂, ... βₙ = Regression coefficients Each coefficient represents the effect of its corresponding independent variable while keeping other variables constant.

### Working Process

### 1. Collect dataset with multiple features.

### 2. Select independent and dependent variables.

### 3. Train the Multiple Linear Regression model.

### 4. Estimate regression coefficients.

### 5. Predict target values.

### 6. Evaluate prediction accuracy.

### Applications

● Student performance prediction ● Stock market analysis ● Medical diagnosis ● Demand forecasting ● Business analytics

### Logistic Regression

Logistic Regression is a supervised machine learning classification algorithm used when the dependent variable is categorical. Although its name contains "Regression," it is primarily used for binary classification problems such as Yes/No, Pass/Fail, Disease/No Disease, Spam/Not Spam, etc. Instead of predicting continuous values, Logistic Regression predicts the probability of belonging to a particular class using the Sigmoid (Logistic) Function. The sigmoid function is: P = 1 / (1 + e−z) where Z = β₀ + β₁X₁ + β₂X₂ + ... + βₙXₙ The sigmoid function converts any real number into a probability between 0 and 1. Based on a threshold (usually 0.5), the probability is converted into a class label.

### Working Process

### 1. Prepare labeled training data.

### 2. Train the Logistic Regression model.

### 3. Calculate probabilities using the sigmoid function.

### 4. Apply threshold classification.

### 5. Predict class labels.

### 6. Evaluate model performance.

### Applications

● Disease prediction ● Email spam detection ● Customer churn prediction ● Fraud detection ● Credit approval systems

### Model Performance Assessment

After training a machine learning model, its performance must be evaluated using suitable evaluation metrics.

### Performance Metrics for Linear Regression

### 1. Mean Absolute Error (MAE): Measures the average absolute diffe rence between actual and predicted

values. Lower MAE indicates better performance.

### 2. Mean Squared Error (MSE): Measures the average squared error between actual and predicted values. It

penalizes larger errors more heavily.

### 3. Root Mean Squared Error (RMSE): The square root of MSE. It represents prediction error in the same units

as the target variable.

### 4. R² Score (Coefficient of Determination): Measures how well the regression model explains the variance in

the data. An R² value closer to 1 indicates better model performance.

### Performance Metrics for Logistic Regression

Accuracy: Measures the percentage of correctly classified instances. Precision: Indicates how many predicted positive cases are actually positive. Recall (Sensitivity): Measures how many actual positive cases are correctly identified. F1-Score: The harmonic mean of Precision and Recall, providing a balanced evaluation.

### Confusion Matrix

A table that summarizes classification performance using: ● True Positives (TP) ● True Negatives (TN) ● False Positives (FP) ● False Negatives (FN) These values help understand where the classifier is making correct and incorrect predictions.

## Theory

### 1. Introduction

Decision Tree is one of the most widely used supervised machine learning algorithms for solving classification and regression problems. It works by recursively dividing the dataset into smaller subsets based on the values of input features. The resulting model resembles a tree -like structure where each internal node  represents a decision based on a feature, each branch represents the outcome of that decision, and each leaf node represents the final predicted class. Decision Trees are popular because they are simple to understand, easy to visualize, and require minimal data preprocessing compared to many other machine learning algorithms. In this experiment, the Decision Tree Classifier is implemented using the Scikit-learn library in Python to classify records from the given sales dataset. The classifier learns patter ns from historical data and predicts the class label (such as order status) for unseen records. The performance of the model is then evaluated using various classification metrics such as accuracy, confusion matrix, precision, recall, and F1-score.

### 2. Supervised Learning

Decision Tree Classification belongs to the category of Supervised Machine Learning . In supervised learning, the model is trained using a dataset that contains both input features (independent variables) and the corresponding target labels (dependent variable). During training, the algorithm learns the relationship between the input features and the target variable. Once trained, the model can accurately predict the class of new unseen data. The objective of supervised learning is to minimiz e prediction errors by learning meaningful patterns from the training dataset.

### 3. Decision Tree Algorithm

A Decision Tree is a flowchart-like structure where the classification process begins from the root node and continues through several decision nodes until it reaches a leaf node, which represents the predicted class. The algorithm repeatedly selects the best feature for splitting the dataset based on an impurity measure such as Gini Index or Entropy (Information Gain). The process continues recursively until one of the stopping conditions is met, such as reaching the maximum tree depth or when all samples belong to the same class. Components of a Decision Tree ● Root Node: Represents the entire dataset and the first decision. ● Decision Node: A node where the dataset is divided based on a feature. ● Branch: Represents the outcome of a decision. ● Leaf Node: Represents the final predicted class. ● Parent Node: A node that splits into child nodes. ● Child Node: A node generated after splitting the parent node.

### 4. Working of Decision Tree

The Decision Tree algorithm follows the steps below:

### 1. Load the dataset.

### 2. Select the target variable for classification.

### 3. Choose the best feature for splitting using Gini Index or Entropy.

### 4. Split the dataset into smaller subsets.

### 5. Repeat the splitting process recursively.

### 6. Stop splitting when the stopping criteria are satisfied.

### 7. Predict the class of new records using the generated tree.

This hierarchical decision -making process enables the model to classify data accurately while maintaining interpretability.

### 5. Splitting Criteria

The quality of each split is determined using an impurity measure.

### (a) Gini Index

The Gini Index measures how often a randomly chosen element would be incorrectly classified if it were randomly labeled according to the distribution of labels. Characteristics: ● Lower Gini value indicates better purity. ● Gini value ranges from 0 to 1. ● A value of 0 indicates a perfectly pure node.

### (b) Entropy and Information Gain

Entropy measures the amount of randomness or uncertainty present in the dataset. The Decision Tree selects the feature that provides the maximum Information Gain, which means the greatest reduction in uncertainty after splitting. Characteristics: ● Higher entropy indicates greater disorder. ● Lower entropy indicates purer nodes. ● Information Gain helps in selecting the optimal feature for splitting.

### 6. Scikit-learn Library

Scikit-learn is a powerful open-source Python library used for machine learning and data mining. It provides efficient implementations of various machine learning algorithms including Decision Trees, Random Forest, Support Vector Machine, Logistic Regression, and many others. In this experiment, Scikit-learn provides: ● Dataset splitting using train_test_split() ● Label encoding using LabelEncoder ● Model creation using DecisionTreeClassifier ● Prediction using predict() ● Performance evaluation using accuracy_score(), confusion_matrix(), and classification_report() ● Tree visualization using plot_tree()

### 7. Dataset Used

The experiment uses the Sales Data Sample  dataset, which contains customer order information including product details, order quantity, sales amount, product line, order month, year, and order status. The target variable selected for classification is: ● STATUS The remaining relevant attributes are used as input features to train the Decision Tree model. Before training, categorical features are converted into numerical form using Label Encoding, and unnecessary columns are removed to improve model performance.

### 8. Model Training and Testing

The dataset is divided into two parts: ● Training Set (80%) – Used to train the Decision Tree model. ● Testing Set (20%) – Used to evaluate the model's performance. The classifier learns decision rules from the training data and predicts the class labels for the testing dataset.

### 9. Model Evaluation

After training, the model performance is evaluated using standard classification metrics. Accuracy Accuracy measures the percentage of correctly classified instances. ● Indicates the overall performance of the classifier. ● Higher accuracy represents better prediction capability.

## Theory

### 1. Introduction

Support Vector Machine (SVM) is a supervised machine learning algorithm used for both classification and regression tasks. It works by finding an optimal decision boundary, known as a hyperplane, that maximizes the margin between different classes. The support vectors are the data points closest to the hyperplane, and they play a crucial role in defining the decision boundary. SVM is highly effective for both linear and non- linear datasets and is widely used due to its high accuracy and robustness.

### 2. Support Vector Machine (SVM)

Support Vector Machine is a powerful learning algorithm that constructs an optimal separating hyperplane between different classes. Unlike many traditional classifiers, SVM focuses on maximizing the distance (margin) between the nearest data points of different classes, thereby improving the model's ability to generalize to unseen data.

### The main components of SVM include:

● Hyperplane: A decision boundary that separates different classes. ● Support Vectors: Data points closest to the hyperplane that determine its position. ● Margin: The maximum distance between the hyperplane and the nearest support vectors. ● Kernel Function: Maps data into a higher-dimensional space when the data is not linearly separable.

### 3. SVM for Classification

In classification problems, SVM separates data into different classes by identifying the optimal hyperplane that maximizes the margin. For non-linearly separable data, kernel functions transform the data into higher dimensions where a linear separation becomes possible.

### The classification process includes:

● Preparing and preprocessing the dataset. ● Selecting relevant features. ● Scaling numerical features. ● Training the SVM classifier. ● Predicting class labels for test data. ● Evaluating model performance using standard metrics.

### 4. SVM for Regression (SVR)

Support Vector Regression (SVR) extends the SVM concept to regression problems by predicting continuous numerical values instead of class labels. Instead of minimizing prediction error directly, SVR attempts to fit the best possible function within a specified error tolerance (ε), while maintaining maximum margin.

### SVR is commonly used for:

● Sales prediction. ● Stock price forecasting. ● Demand forecasting. ● Weather prediction.

### 5. SVM for Outlier Detection

Support Vector Machine can also detect anomalies using One-Class SVM. The algorithm learns the normal behavior of the training data and identifies observations that significantly differ from the learned pattern as outliers. Applications include: ● Fraud detection. ● Network intrusion detection. ● Fault detection in industrial systems. ● Medical anomaly detection.

### 6. Kernel Functions

Kernel functions enable SVM to solve non-linear problems by transforming data into higher-dimensional feature spaces. Common kernel functions include: ● Linear Kernel: Suitable for linearly separable data. ● Polynomial Kernel: Captures polynomial relationships between features. ● Radial Basis Function (RBF) Kernel: Most widely used kernel for handling complex and non- linear datasets. ● Sigmoid Kernel: Similar to neural network activation functions for certain applications.

### 7. Applications of Support Vector Machine

Support Vector Machine is widely used in various domains, including: ● Email spam classification. ● Image and face recognition. ● Medical disease diagnosis. ● Handwritten character recognition. ● Customer churn prediction. ● Financial risk analysis.

● Text and sentiment classification. ● Fraud and anomaly detection.

### 8. Advantages

● Provides high accuracy for classification and regression tasks. ● Performs well with high-dimensional datasets. ● Effective for both linear and non-linear data through kernel functions. ● Reduces overfitting by maximizing the decision margin. ● Suitable for small and medium-sized datasets.

### 9. Limitations

● Training can be computationally expensive for large datasets. ● Selection of kernel and hyperparameters significantly affects performance. ● Requires feature scaling for optimal results. ● Less efficient for extremely large datasets. ● Model interpretation is relatively difficult compared to simpler algorithms.

**Aim:** To implement AdaBoost Classifier and XGBoost algorithms for solving classification problems and evaluate their performance using appropriate machine learning evaluation metrics

**Learning Objective:** To understand the working principles of AdaBoost Classifier and XGBoost algorithms, implement these ensemble learning techniques for classification, and evaluate their performance using appropriate machine learning evaluation metrics.

**Tools:** VS Code, I-Python Notebook, Python, Pandas, NumPy, Scikit-learn, and XGBoost.

## Theory

### 1. Introduction

Ensemble learning is a machine learning technique in which multiple models are combined to produce a stronger and more accurate predictive model. Boosting is an ensemble learning approach where weak learners are trained sequentially, and each new learner focuses on improving the errors made by the previous learners. AdaBoost and XGBoost are widely used boosting algorithms for solving classification and regression problems.

### 2. Boosting

Boosting combines several weak learners to create a strong learner. Unlike bagging, where models are trained independently, boosting trains models sequentially. Each successive model attempts to improve the performance of the previous model by giving greater attention to incorrectly predicted observations or by reducing the remaining prediction errors. The general boosting process includes:  Training an initial weak learner on the dataset.  Identifying errors made by the model.  Giving more attention to difficult or incorrectly predicted observations.  Training the next learner to improve the previous model.  Repeating the process for a specified number of iterations.  Combining the predictions of all learners to produce the final result.

### 3. AdaBoost (Adaptive Boosting)

AdaBoost, or Adaptive Boosting, is an ensemble learning algorithm that combines multiple weak classifiers to form a strong classifier. It works by training models sequentially and adaptively changing the importance of training samples. Initially, all data points are assigned equal weights. After each iteration, the weights of incorrectly classified samples are increased so that the next weak learner focuses more on these difficult samples. The main components of AdaBoost include:  Weak Learner: A simple model, commonly a shallow decision tree or decision stump.  Sample Weights: Values assigned to training samples to indicate their importance.  Classifier Weight: The importance assigned to each weak learner based on its performance.

 Strong Classifier: The final model obtained by combining the predictions of all weak learners.

### 4. Working of AdaBoost

The AdaBoost algorithm works in the following steps:

### 1. Equal weights are assigned to all training samples.

### 2. A weak classifier is trained on the weighted dataset.

### 3. The predictions of the classifier are compared with the actual class labels.

### 4. The error of the weak classifier is calculated.

### 5. Higher weights are assigned to incorrectly classified samples, while correctly classified samples

receive relatively less emphasis.

### 6. A new weak classifier is trained with greater focus on the difficult samples.

### 7. The process is repeated for a predefined number of estimators.

### 8. The predictions of all weak classifiers are combined using weighted voting to produce the final

classification result.

### 5. Advantages of AdaBoost

 Improves the performance of weak classifiers by combining them into a strong model.  Focuses on difficult and misclassified samples during training.  Can provide high classification accuracy.  Simple and effective for many supervised learning problems.  Can be implemented using different weak learners.

### 6. Limitations of AdaBoost

 Sensitive to noisy data and outliers.  Incorrectly classified noisy observations may receive increased importance.  Performance depends on the selection of appropriate weak learners.  Training may become computationally expensive when a large number of estimators is used.

### 7. XGBoost (Extreme Gradient Boosting)

XGBoost stands for Extreme Gradient Boosting. It is an optimized implementation of the gradient boosting technique designed for efficiency, speed, and high predictive performance. XGBoost uses decision trees as base learners and builds them sequentially, with each new tree attempting to correct the errors made by the previous trees. It also includes regularization to control model complexity and improve generalization.

### 8. Working of XGBoost

The XGBoost algorithm works by sequentially building decision trees to reduce the errors of previous predictions. The general process includes:

### 1. An initial prediction is generated using a base model.

### 2. The difference between actual and predicted values is calculated using a loss function.

### 3. A new decision tree is trained to reduce the previous errors.

### 4. The predictions of the new tree are added to the predictions from earlier trees.

### 5. Regularization is applied to control the complexity of the trees and reduce overfitting.

### 6. The process continues until a specified number of boosting rounds or another stopping criterion is

reached.

### 7. The final prediction is obtained by combining the contributions of all decision trees.

Mathematically, the XGBoost prediction can be represented as: ŷᵢ = Σ fₖ(xᵢ)

### where:

 ŷᵢ represents the final predicted value.  fₖ(xᵢ) represents the prediction of the k-th decision tree.  K represents the total number of trees in the ensemble. XGBoost optimizes an objective function consisting of a loss function and a regularization term: Objective = Loss Function + Regularization Term The loss function measures the difference between actual and predicted values, while the regularization term penalizes overly complex models.

### 9. Important Features of XGBoost

 Regularization: Helps control model complexity and reduce overfitting.  Sequential Learning: Each tree is trained to improve the errors of previous trees.  Parallel Processing: Optimizations allow efficient processing during model training.  Missing Value Handling: Supports handling missing values during tree construction and prediction.  Feature Importance: Can identify the relative importance of input features.  Scalability: Suitable for handling large and complex datasets.

### 10. Advantages of XGBoost

 Provides high predictive performance for many machine learning tasks.  Efficient and scalable for large datasets.  Uses regularization to improve generalization and reduce overfitting.  Supports parallel processing and efficient computation.  Can handle missing values.  Provides feature importance for analyzing model behavior.  Can be used for both classification and regression problems.

### 11. Limitations of XGBoost

 Can be computationally intensive on systems with limited resources.  Requires proper hyperparameter tuning for optimal performance.  May overfit when too many trees or inappropriate parameter values are used.  Can be sensitive to noisy data and outliers.  Is generally more difficult to interpret than simpler machine learning models.

# Experiment 6

**Aim:** Implementation of K-Means Clustering

**Learning Objective:** To understand the concept of unsupervised learning and implement the K-Means Clustering algorithm to group similar data points into different clusters based on their features, and to analyze and interpret the clusters formed using appropriate visualization techniques.

**Tools:** VS Code, I-Python Notebook.

## Theory

### 1. Introduction

Machine learning algorithms are broadly divided into supervised and unsupervised learning. In supervised learning, every training example has a known output label, and the model learns to map inputs to those labels. In many real-world situations, however, data is available without any labels — for example, a list of customers, players or documents with no predefined categories. Unsupervised learning deals with such unlabelled data and tries to discover hidden structure, patterns or groupings within it. Clustering is the most common unsupervised learning task. Its goal is to divide a dataset into groups, called clusters, such that data points within the same cluster are highly similar to each other while points in different clusters are dissimilar. K-Means Clustering is one of the simplest and most widely used clustering algorithms. It is popular because it is easy to understand, computationally efficient and works well on large datasets with numerical features.

### 2. K-Means Clustering

K-Means is a centroid-based clustering algorithm. It divides the dataset into a fixed number of clusters, denoted by K, which must be decided before running the algorithm. Each cluster is represented by a single central point known as the centroid, which is calculated as the mean (average) of all the data points belonging to that cluster. This is why the algorithm is called K-"Means". Every data point is assigned to exactly one cluster — the cluster whose centroid is nearest to it. Because the assignment depends on distance, K-Means naturally forms compact, roughly spherical groups around each centroid. The algorithm repeatedly improves the position of the centroids until the clusters no longer change, at which point the model is said to have converged. The main components of K-Means include: ● K (Number of Clusters): A user-defined value that specifies how many groups the data should be divided into. ● Centroid: The centre of a cluster, computed as the mean of all data points assigned to it. ● Distance Measure: Usually Euclidean distance, used to determine which centroid a data point is closest to. ● Cluster Label: The cluster number (0, 1, 2, …) assigned to each data point after clustering. ● Inertia (WCSS): The Within-Cluster Sum of Squares, which measures how tightly the points are grouped around their centroids.

### 3. Working of K-Means

K-Means follows an iterative refinement procedure that alternates between two main steps: an assignment step and an update step. Initially, K centroids are placed in the feature space. In scikit-learn, this is done using the k-means++ strategy, which spreads the initial centroids far apart to obtain better and more stable results than purely random initialisation. In the assignment step, the distance between each data point and every centroid is calculated, and the point is assigned to the nearest centroid. In the update step, each centroid is moved to the mean position of all the points that were assigned to it. These two steps are repeated until the centroids stop moving significantly or a maximum number of iterations is reached. Since the final result can depend on the starting centroids, the algorithm is usually run several times with different initialisations (controlled by the n_init parameter), and the run with the lowest inertia is selected. The clustering process includes: ● Choosing the number of clusters K. ● Initialising K centroids. ● Assigning each data point to its nearest centroid. ● Recalculating each centroid as the mean of its assigned points. ● Repeating the assignment and update steps until convergence. ● Obtaining the final cluster labels and centroids.

### 4. Objective Function

The goal of K-Means is to make each cluster as compact as possible. Mathematically, it minimises the Within-Cluster Sum of Squares (WCSS), which is the total squared distance between every data point and the centroid of the cluster it belongs to: J = Σ (k = 1 to K) Σ (x ∈ Cₖ) ‖x − μₖ‖² Here, Cₖ is the set of data points in cluster k, x is a data point, and μₖ is the centroid of cluster k. Each assignment step and each update step can only decrease (or keep constant) the value of J, which guarantees that the algorithm converges. A smaller value of J indicates tighter and more well-defined clusters. However, K-Means finds a local minimum, not necessarily the global minimum, which is why multiple initialisations are used.

### 5. Choosing the Value of K

Since K must be specified before training, selecting a suitable value is one of the most important decisions in K-Means. If K is too small, genuinely different groups are merged together; if K is too large, natural groups are split into meaningless fragments. Several methods are used to choose an appropriate value: ● Elbow Method: WCSS is plotted for different values of K. WCSS always decreases as K increases, but the point where the rate of decrease sharply slows down (the "elbow") is chosen as the optimal K. ● Silhouette Score: Measures how similar a point is to its own cluster compared to the nearest other cluster. The score ranges from −1 to 1, and higher values indicate better-separated clusters. ● Domain Knowledge: The number of meaningful groups may already be known from the problem. In this experiment, K = 3 is chosen to represent three performance tiers of chess candidates.

### 6. Importance of Feature Scaling

K-Means relies entirely on distance calculations, so the scale of each feature has a direct effect on the clusters formed. Features with large numerical ranges dominate the distance measure and effectively decide the clusters on their own. In this experiment, the Elo rating ranges from about 2400 to 2880, while the win ratio lies between 0 and 1. Without scaling, the win ratio would have almost no influence on the clustering. To avoid this, the features are standardized using StandardScaler, which transforms each feature to have a mean of zero and a standard deviation of one using Z = (X − μ) / σ. After standardization, both Elo rating and win ratio contribute equally to the distance, and the resulting clusters reflect both playing strength and performance. The cluster centroids reported by the model are therefore in scaled coordinates.

### 7. Applications of K-Means Clustering

Because it is simple and scalable, K-Means is used in a wide variety of fields to discover natural groupings in data. Some common applications include: ● Customer segmentation for targeted marketing. ● Grouping players or teams by performance level in sports analytics. ● Image segmentation and colour quantization. ● Document and news article clustering. ● Anomaly detection by identifying points far from any centroid. ● Recommendation systems and market basket grouping.

### 8. Advantages

● Simple to understand and easy to implement. ● Computationally efficient and scales well to large datasets. ● Produces compact clusters that are easy to interpret through their centroids. ● Guaranteed to converge in a finite number of iterations. ● Works very well when clusters are roughly spherical and well separated.

### 9. Limitations

● The number of clusters K must be specified in advance. ● Results depend on the initial placement of centroids and may reach a local minimum. ● Sensitive to outliers, which can pull centroids away from the true cluster centre. ● Requires feature scaling, since it is based on distance. ● Assumes spherical clusters of similar size and cannot handle complex, non-convex shapes.

# Experiment 7

**Aim:** Implementation of PCA for Dimensionality Reduction

**Learning Objective:** To understand the principles of dimensionality reduction using Principal Component Analysis (PCA), project high-dimensional data into a lower-dimensional space, and evaluate the performance of a machine learning classifier (KNN) on the dimensionally reduced feature set along with visualizing the data along the top principal components.

**Tools:** VS Code, I-Python Notebook.

## Theory

### 1. Introduction

Real-world datasets often contain a large number of features. Many of these features are correlated with each other and carry overlapping information — for example, a chess player's classical, rapid and blitz ratings all reflect overall playing strength. As the number of features grows, the data becomes sparse, computation becomes slower, visualization becomes impossible beyond three dimensions, and machine learning models become more prone to overfitting. This problem is commonly known as the curse of dimensionality. Dimensionality reduction techniques address this problem by representing the data with fewer variables while preserving as much useful information as possible. There are two main approaches: feature selection, which keeps a subset of the original features, and feature extraction, which creates new features from combinations of the original ones. Principal Component Analysis (PCA) is the most widely used feature extraction technique.

### 2. Principal Component Analysis (PCA)

Principal Component Analysis (PCA) is an unsupervised dimensionality reduction technique that projects high-dimensional data into a lower-dimensional subspace while retaining as much variance as possible. It is called unsupervised because it uses only the input features and does not consider the target labels. PCA transforms a set of possibly correlated variables into a new set of linearly uncorrelated variables called principal components. Each principal component is a linear combination of the original features. The first principal component (PC1) points in the direction along which the data varies the most. The second principal component (PC2) captures the next largest amount of variance while being orthogonal (perpendicular) to PC1, and so on. By keeping only the first few components, the data can be represented in far fewer dimensions with minimal loss of information. The main components of PCA include: ● Principal Components: New orthogonal axes formed as linear combinations of the original features. ● Eigenvectors: Define the direction of each principal component in the original feature space. ● Eigenvalues: Indicate the amount of variance captured along each principal component. ● Explained Variance Ratio: The fraction of the total variance retained by each component. ● Loadings: The weights showing how strongly each original feature contributes to a component.

### 3. Working of PCA

PCA is carried out through a sequence of mathematical steps that convert the original data into a new coordinate system defined by the principal components. Step 1 – Standardization: Each feature is scaled so that it has a mean of zero and a variance of one. This ensures that features measured on large scales do not dominate the analysis: Z = (X − μ) / σ Step 2 – Covariance Matrix Computation: The covariance matrix is calculated to capture how every pair of features varies together. Positive values indicate features that increase together, and negative values indicate features that move in opposite directions: Σ = (1 / (n − 1)) · Zᵀ Z Step 3 – Eigenvalue and Eigenvector Decomposition: The eigenvalues (λ) and eigenvectors (v) of the covariance matrix are computed. Each eigenvector gives the direction of a principal component, and its eigenvalue gives the variance along that direction: Σ v = λ v Step 4 – Selecting Principal Components: The eigenvalues are sorted in descending order, and the top k eigenvectors corresponding to the largest eigenvalues are selected. These eigenvectors form the columns of the projection matrix W. Step 5 – Projecting the Data: The standardized data matrix Z is multiplied by the projection matrix W to obtain the data in the new k-dimensional feature space: X_pca = Z · W

### 4. Explained Variance

The explained variance ratio of a component is its eigenvalue divided by the sum of all eigenvalues. It shows what percentage of the information in the original data is retained by that component. The cumulative explained variance of the first k components indicates how much information is preserved after reducing the data to k dimensions. When the original features are strongly correlated, a small number of components can capture most of the variance. When the features are largely independent of each other — as in a randomly generated dataset — the variance is spread more evenly across components, and two components retain a smaller share of the total information. Examining the explained variance therefore helps judge how much is lost during reduction.

### 5. PCA with K-Nearest Neighbors (KNN)

PCA is commonly used as a preprocessing step before training a classifier. In this experiment, a K-Nearest Neighbors (KNN) classifier is trained on the two principal components instead of the original features. KNN classifies a new data point by finding the K closest training points and assigning the class that appears most

frequently among them. Since KNN is distance-based, it benefits from standardized inputs and from reducing the number of dimensions. The accuracy of the classifier on the reduced data shows how well the class structure is preserved after projection. If the principal components retain the features that separate the classes, accuracy remains high; if important information is discarded, accuracy drops. The scatter plot of PC1 against PC2, coloured by class, provides a visual check of how well the classes are separated in the reduced space. The process includes: ● Generating and preparing the dataset. ● Creating the target class labels (player tiers). ● Standardizing all numerical features. ● Applying PCA to obtain two principal components. ● Splitting the reduced data into training and testing sets. ● Training the KNN classifier and evaluating its accuracy.

### 6. Choosing the Number of Components

Selecting the number of components is a trade-off between simplicity and information retained. Too few components may discard useful information, while too many reduce the benefit of dimensionality reduction. Common approaches include: ● Cumulative Explained Variance: Select the smallest number of components that retain a desired percentage (for example 90–95%) of the total variance. ● Scree Plot: Plot the eigenvalues against the component number and choose the point where the curve flattens. ● Visualization Needs: Two or three components are chosen when the main goal is to plot and visually inspect the data.

### 7. Applications of PCA

PCA is used across many domains wherever high-dimensional data must be simplified, visualized or compressed. Some common applications include: ● Visualization of high-dimensional datasets in 2D or 3D. ● Image compression and face recognition (Eigenfaces). ● Noise reduction in signals and images. ● Feature extraction before training machine learning models. ● Genomics and bioinformatics data analysis. ● Finance and sports performance analytics.

### 8. Advantages

● Reduces the number of features, lowering computation time and memory usage. ● Removes multicollinearity by producing uncorrelated components. ● Makes it possible to visualize high-dimensional data in 2D or 3D. ● Reduces noise and can help prevent overfitting. ● Unsupervised, so it does not require class labels.

### 9. Limitations

● Principal components are difficult to interpret in terms of the original features. ● Some information is lost when too few components are retained. ● Captures only linear relationships between features. ● Sensitive to feature scaling and to outliers. ● Maximizing variance does not always maximize class separability.

# Experiment 8

**Aim:** Implementation of Reinforcement Learning

**Learning Objective:** To understand the basic concepts of reinforcement learning, represent a decision- making problem using states, actions, rewards and transitions, and implement the Q-learning algorithm in Python to train an agent that learns an effective path to a goal using the learned Q-table.

**Tools:** VS Code, I-Python Notebook.

## Theory

### 1. Introduction

Machine learning is commonly divided into three paradigms: supervised learning, unsupervised learning and reinforcement learning. In supervised learning the model learns from labelled examples, and in unsupervised learning it discovers structure in unlabelled data. Reinforcement Learning (RL) is different from both, because the learner is not given a dataset at all. Instead, it learns by interacting with an environment and receiving feedback in the form of rewards or penalties. Reinforcement learning is inspired by the way humans and animals learn through trial and error. A child learning to walk, or a chess player improving through practice, tries different actions, observes the consequences and gradually prefers the actions that lead to good outcomes. In the same way, an RL agent explores its environment, collects experience, and slowly builds a strategy that maximizes the total reward it receives over time.

### 2. Reinforcement Learning

Reinforcement Learning is a machine learning approach in which an agent learns to make a sequence of decisions by interacting with an environment. At each time step, the agent observes the current state, chooses an action, receives a reward, and moves to a new state. The objective of the agent is not to maximize the immediate reward, but to learn a policy that maximizes the cumulative reward collected over an entire episode. This interaction is usually modelled as a Markov Decision Process (MDP), in which the next state depends only on the current state and the action taken, and not on the full history of earlier states. An MDP is described by a set of states, a set of actions, a transition rule that defines how actions change states, and a reward function that defines the feedback received for each transition. The basic elements of Reinforcement Learning include: ● Agent: The learner or decision-making entity that takes actions. ● Environment: The system with which the agent interacts and which responds to its actions. ● State (s): The current situation of the agent within the environment. ● Action (a): A decision or move available to the agent in a given state. ● Reward (r): The numerical feedback received after taking an action. ● Policy (π): The strategy the agent uses to select actions in each state. ● Q-value: The expected cumulative reward of taking a particular action in a particular state and acting well afterwards.

### 3. Rewards, Returns and the Discount Factor

The reward signal tells the agent how good or bad an individual action was, but a good decision-maker must also consider the long-term consequences of its actions. The total reward the agent expects to collect from a state onwards is called the return. Since future rewards are less certain than immediate ones, they are multiplied by a discount factor γ (gamma), a value between 0 and 1. G = r₁ + γ r₂ + γ² r₃ + … A value of γ close to 0 makes the agent short-sighted and focused only on immediate rewards, while a value close to 1 makes it far-sighted and willing to accept small penalties now for a larger reward later. In this experiment γ = 0.95, so the agent values reaching the goal highly even when it is several moves away.

### 4. Q-Learning

Q-learning is a model-free, value-based reinforcement learning algorithm. It is called model-free because the agent does not need to know the transition rules or the reward function in advance; it learns purely from experience. It is called value-based because, instead of learning the policy directly, it learns a value for every state-action pair and then chooses the action with the highest value. These values are stored in a Q-table, which has one row for each state and one column for each action. Initially all entries are zero. After every action, the agent updates the corresponding entry using the reward it received and the best estimated value of the next state, according to the Q-learning update equation: Q(s, a) ← Q(s, a) + α [ r + γ · max Q(s′, a′) − Q(s, a) ] Here, s is the current state, a is the action taken, r is the reward received, s′ is the next state and a′ ranges over all possible actions in s′. The term r + γ · max Q(s′, a′) is the new estimate of the value, and the difference between this estimate and the old value is called the temporal difference (TD) error. The learning rate α (alpha), between 0 and 1, controls how much of this error is used to update the old value. A high α makes the agent learn quickly from new experience, while a low α makes learning slower but more stable.

### 5. Exploration vs Exploitation

A key challenge in reinforcement learning is balancing exploration and exploitation. Exploitation means choosing the action that currently has the highest Q-value, using what the agent already knows. Exploration means trying a random action to discover whether something better exists. An agent that only exploits may get stuck with a poor strategy, while an agent that only explores never makes use of what it has learned. Q-learning commonly handles this using the epsilon-greedy strategy. With probability ε (epsilon) the agent selects a random action, and with probability 1 − ε it selects the action with the highest Q-value. Training begins with ε = 1.0, so the agent explores completely at random. After every episode ε is multiplied by a decay factor (0.995 in this experiment) until it reaches a minimum value (0.05). As a result, the agent explores widely in the beginning and gradually shifts towards exploiting the knowledge it has gained.

### 6. Problem Formulation: 4 × 4 Grid World

In this experiment, the environment is a 4 × 4 grid containing 16 states numbered from 0 to 15. The agent starts at state 0 (top-left corner) and must reach the goal at state 15 (bottom-right corner). In each state, the

agent can choose one of four actions: Up, Down, Left or Right. If a move would take the agent outside the grid, it remains in the same cell. The reward structure guides the agent towards an efficient path. Reaching the goal gives a reward of +10, hitting a wall and staying in place gives a penalty of −2, and every other move gives a penalty of −1. Because every extra step costs a penalty, the agent learns that the best strategy is to reach the goal using the fewest possible moves, which on a 4 × 4 grid is exactly six moves. The Q-learning algorithm proceeds as follows: ● Initialize the Q-table with zeros. ● For each episode, place the agent at the starting state. ● Select an action using the epsilon-greedy strategy. ● Execute the action and observe the reward and the next state. ● Update the Q-value using the Q-learning equation. ● Move to the next state and repeat until the goal is reached or the maximum number of steps is completed. ● Decay epsilon after each episode. ● After training, choose the action with the highest Q-value at each state to follow the learned policy.

### 7. Applications of Reinforcement Learning

Reinforcement learning is used wherever a system must make a sequence of decisions under uncertainty and can learn from feedback. Some common applications include: ● Game playing, such as chess, Go and video games. ● Robotics, navigation and path planning. ● Autonomous vehicles and traffic signal control. ● Recommendation systems and online advertising. ● Resource management, scheduling and inventory control. ● Algorithmic trading and portfolio management.

### 8. Advantages

● Does not require labelled training data; learns directly from interaction. ● Q-learning is model-free and does not need knowledge of the environment's rules. ● Can learn long-term strategies by considering future rewards. ● Adapts to changing environments through continued learning. ● Simple to implement for problems with small, discrete state and action spaces.

### 9. Limitations

● Requires a large number of episodes to learn an effective policy. ● The Q-table grows with the number of states and actions, making it impractical for large or continuous problems. ● Performance depends heavily on the reward design and on hyperparameters such as α, γ and ε. ● Random exploration can be costly or unsafe in real-world environments. ● Learned Q-values may vary between runs because exploration is stochastic.

## Code

```python
import numpy as np

# 4 x 4 grid
n_states = 16
n_actions = 4

# Actions: 0=Up, 1=Down, 2=Left, 3=Right
q_table = np.zeros((n_states, n_actions))

alpha = 0.8          # learning rate
gamma = 0.95         # discount factor
epsilon = 1.0        # exploration probability
epsilon_min = 0.05
epsilon_decay = 0.995
episodes = 1000
max_steps = 50

start_state = 0
goal_state = 15

def next_state(state, action):
    row, col = divmod(state, 4)

    if action == 0 and row > 0:      # Up
        row -= 1
    elif action == 1 and row < 3:    # Down
        row += 1
    elif action == 2 and col > 0:    # Left
        col -= 1
    elif action == 3 and col < 3:    # Right
        col += 1

    return row * 4 + col

# Training
for episode in range(episodes):
    state = start_state

    for step in range(max_steps):
        if np.random.rand() < epsilon:
            action = np.random.randint(n_actions)
        else:
            action = np.argmax(q_table[state])

        new_state = next_state(state, action)

        if new_state == goal_state:
            reward = 10
        elif new_state == state:
            reward = -2
        else:
            reward = -1

        q_table[state, action] += alpha * (
            reward
            + gamma * np.max(q_table[new_state])
            - q_table[state, action]
        )

        state = new_state

        if state == goal_state:
            break

    epsilon = max(epsilon_min, epsilon *
epsilon_decay)

print("Learned Q-table:")
print(np.round(q_table, 2))
```

## Theory

### 1. Introduction

Every machine learning model has two kinds of settings. Model parameters, such as the weights of a linear model or the support vectors of an SVM, are learned automatically from the training data. Hyperparameters, on the other hand, are settings that must be chosen before training begins — for example, the regularization strength C and the kernel of an SVM, the number of neighbours K in KNN, or the depth of a decision tree. Hyperparameters control how the model learns, and they cannot be learned from the data in the same way as ordinary parameters. The choice of hyperparameters has a strong effect on model performance. Poorly chosen values can cause underfitting, where the model is too simple to capture the patterns in the data, or overfitting, where the model memorizes the training data and performs badly on new data. Hyperparameter tuning is the process of systematically searching for the combination of hyperparameter values that gives the best performance on unseen data.

### 2. Hyperparameter Tuning

Manually trying different hyperparameter values is slow, error-prone and difficult to reproduce. Automated search methods solve this by defining a search space — the set of values each hyperparameter is allowed to take — and evaluating many candidate combinations using a consistent performance measure. The combination with the best score is then selected and used to train the final model. A candidate combination should never be judged using the test set, because the test set must remain completely unseen until the final evaluation. If the test set were used to choose hyperparameters, the reported accuracy would be overly optimistic. Instead, each candidate is evaluated using cross-validation on the training data only. The main components of hyperparameter tuning include: ● Estimator: The model or pipeline whose hyperparameters are being tuned, such as an SVM classifier. ● Search Space: The set of possible values (or distributions) for each hyperparameter. ● Scoring Metric: The measure used to compare candidates, such as accuracy, F1-score or RMSE. ● Cross-Validation Strategy: The method used to estimate how well each candidate generalizes, such as 5-fold cross-validation. ● Best Estimator: The model retrained on the full training set using the best hyperparameters found.

### 3. K-Fold Cross-Validation

Cross-validation provides a reliable estimate of how well a model with given hyperparameters will perform on unseen data. In K-fold cross-validation, the training data is divided into K equal parts called folds. The model is trained on K − 1 folds and validated on the remaining fold, and this process is repeated K times so that every fold is used for validation exactly once. The final score is the average of the K validation scores: CV Score = (1 / K) Σ (i = 1 to K) Scoreᵢ Averaging over several folds reduces the effect of a single lucky or unlucky split and gives a more stable comparison between candidates. For classification problems, stratified K-fold is used by default, so that each fold keeps the same proportion of classes as the full dataset. In this experiment, 5-fold cross-validation is used, which means every candidate combination is trained and evaluated five times.

### 4. GridSearchCV

GridSearchCV performs an exhaustive search over a manually specified grid of hyperparameter values. It evaluates every possible combination of the values provided, using cross-validation for each one, and returns the combination with the highest average score. For example, a grid with 4 values of C, 4 values of gamma and 2 kernels contains 4 × 4 × 2 = 32 combinations, and with 5-fold cross-validation this requires 160 model fits. The main strength of GridSearchCV is that it is thorough: if the best combination lies within the grid, it is guaranteed to be found. However, the number of combinations grows multiplicatively with every hyperparameter and every additional value, which makes grid search very expensive for large search spaces. It also only tests the exact values listed, so a better value lying between two grid points can be missed.

### 5. RandomizedSearchCV

RandomizedSearchCV, instead of testing every combination, samples a fixed number of random combinations (controlled by the n_iter parameter) from the specified search space. Hyperparameters can be given either as lists of values or as continuous probability distributions. For parameters such as C and gamma, whose useful values span several orders of magnitude, a log-uniform distribution is commonly used so that small and large values are sampled equally often. Because the number of candidates is fixed in advance, the cost of RandomizedSearchCV does not grow with the size of the search space. In practice, only a few hyperparameters usually have a large effect on performance, and random sampling explores many more distinct values of those important hyperparameters than a grid of the same size. As a result, randomized search often finds results that are as good as or better than grid search with fewer evaluations. Its limitation is that it is not exhaustive, so the very best combination is not guaranteed to be sampled.

### 6. Tuning a Support Vector Machine

In this experiment, a Support Vector Machine (SVM) classifier is tuned to predict the performance tier of chess players. The SVM is placed inside a Pipeline together with StandardScaler. Using a pipeline ensures that the scaler is fitted only on the training folds during cross-validation, which prevents information from the validation fold leaking into the training process. Hyperparameters of a step inside a pipeline are referred to using the step name followed by two underscores, such as svc__C.

The hyperparameters tuned for the SVM are: ● C (Regularization Parameter): Controls the trade-off between a smooth decision boundary and classifying training points correctly. A small C gives a wider, simpler margin, while a large C fits the training data more closely. ● gamma: Defines how far the influence of a single training point reaches for the RBF kernel. A small gamma gives smooth, broad decision boundaries, while a large gamma gives complex, tightly fitted boundaries. ● kernel: Determines the shape of the decision boundary — linear for straight-line boundaries or RBF for non-linear boundaries. The tuning process includes: ● Preparing the dataset and creating the target labels. ● Splitting the data into training and testing sets. ● Training a baseline model with default hyperparameters. ● Defining the parameter grid and parameter distributions. ● Running GridSearchCV and RandomizedSearchCV with 5-fold cross-validation. ● Evaluating the best models on the test set and comparing the results.

### 7. Applications of Hyperparameter Tuning

Hyperparameter tuning is a standard step in almost every practical machine learning workflow. Some common applications include: ● Selecting C, gamma and kernel for Support Vector Machines. ● Choosing the number of neighbours and distance metric for KNN. ● Tuning tree depth and number of estimators in Random Forests and Gradient Boosting. ● Selecting learning rate, batch size and layer sizes in neural networks. ● Choosing regularization strength in linear and logistic regression. ● Building automated machine learning (AutoML) pipelines.

### 8. Advantages

● Improves model accuracy and generalization compared to default settings. ● Replaces manual trial-and-error with a systematic and reproducible process. ● Uses cross-validation, giving reliable estimates and reducing overfitting to one split. ● GridSearchCV is exhaustive within the given grid. ● RandomizedSearchCV handles large and continuous search spaces efficiently.

### 9. Limitations

● Computationally expensive, since every candidate is trained K times. ● The cost of GridSearchCV grows rapidly as more hyperparameters and values are added. ● RandomizedSearchCV may miss the best combination because it is not exhaustive. ● Results depend on how well the search space is defined. ● Over-tuning on a small dataset can still overfit the cross-validation folds.
